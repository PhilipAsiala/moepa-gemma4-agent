# Google – The Gemma 4 Developer Agent Paper Track

Official competition: https://www.kaggle.com/competitions/gemma-4-developer-agent-paper

> Submit a Research Paper advancing the state-of-the-art for agentic software engineering.

## Motivation

Today’s best coding agents rely on massive API models in the cloud. This track asks: what if every developer could rely on an autonomous agent equally capable **offline, on consumer hardware**?

The featured competition ranks agents by bugs fixed. This **Paper Track** invites novel, unpublished research (or a documented approach to the prediction competition) that advances agentic software engineering. Winning papers may be highlighted at a Google-hosted event (e.g. NeurIPS expo workshop) and awarded prizes.

Participation in the main coding competition is **not required**, though joining both is encouraged.

## Evaluation rubric

Each criterion is scored 0–5; final score = average of five:

| Category | Description |
|----------|-------------|
| **Novelty** | New insights, deeper understanding, or important properties of existing methods |
| **Quality** | Generality beyond the competition; transfer to similar problems |
| **Relevance** | Significance / impact for software engineering and agentic learning |
| **Verifiability** | Enough detail to understand the method and how data was obtained / analyzed |
| **Clarity** | Clear presentation and writing |

Three paper awards go to the highest-scoring submissions. Rubric scores are not shared with entrants. Ties break to the paper entered first. Disqualified winners cascade to the next rank.

## Submission requirements

A valid submission needs a **Kaggle Writeup** with:

1. Title and subtitle  
2. Abstract  
3. Introduction  
4. Description of the research (methods and experiments)  
5. Related works and citations  

Optional:

- **Public Notebook** — linked in Project Links; must be publicly accessible without login/paywall. Private Kaggle notebooks attached to a public writeup are auto-made public after the deadline.
- **Public Project Link** — instead of (or in addition to) the writeup body, an arXiv-ready PDF (LaTeX/Word) that is publicly accessible.

Create via **New Writeup**, then use **Submit** in the top right after saving.

### Submission details

- **Scope:** ≤ **3,000 words**, original unpublished research  
- **Non-archival:** Does not prevent later conference / venue submission  
- Identity verification is required to submit  

## Encouraged topics

- **Tuning & Optimization** — PEFT and RL for SWE agents  
- **Code Comprehension** — code-graph generation, parsing, embeddings  
- **Tasks & Benchmarks** — new tasks, eval datasets, structured code generation resources  
- **Graph Reasoning** — LLM reasoning over large-scale graphs
